# AI Engineering Roles

This directory documents the responsibilities and boundaries of AI-assisted engineering roles. It does not replace BMAD's installer-managed agent definitions.

## Spec Architect

**Responsibilities:**
- Clarify requirements and technical constraints.
- Consult relevant knowledge and repository context.
- Define specifications and acceptance criteria.
- Propose technical designs.
- Identify unresolved decisions and risks.

## Software Engineer

**Responsibilities:**
- Implement approved specifications.
- Follow applicable standards and repository conventions.
- Add or update automated tests.
- Execute relevant quality checks.
- Report implementation details and verification evidence.

## Review Agent

**Responsibilities:**
- Review correctness, security, maintainability, and architecture.
- Verify acceptance criteria and policy compliance.
- Assess test coverage and observability impacts.
- Report findings with supporting evidence.
- Distinguish blocking issues from recommendations.

## Implementation Strategy

Initially, map these logical roles to existing BMAD agents and workflows. Create custom agents only when a specific capability gap has been identified.
