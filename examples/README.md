# Engineering Examples

Store concise, sanitized examples that help engineers and AI agents understand recommended practices and anti-patterns.

## Good Practices

The `good-practices/` directory contains reviewed examples aligned with validated engineering standards.

## Anti-Patterns

The `anti-patterns/` directory contains examples of problematic approaches and explains why they should be avoided.

## Requirements

Every example should include:

- Context and problem addressed.
- Relevant language or framework version, where applicable.
- Explanation of the recommended or problematic approach.
- References to related knowledge documents.
- Verification status.

Remove secrets, personal data, and confidential implementation details.

Examples are illustrative unless explicitly linked to a validated engineering standard.
